# Twofold

A cozy web app for long-distance couples: a shared apartment, Hearts, and synchronous games.

## Run locally

1. Copy env vars and fill in your Supabase project values (optional until auth is wired):

```bash
cp .env.example .env.local
```

2. Install dependencies (already done if you just cloned a completed install):

```bash
npm install
```

3. Start the Next.js dev server:

```bash
npm run dev
```

4. Open [http://localhost:3000](http://localhost:3000).
